# Support

Intelli Git is distributed as a proprietary Visual Studio Code extension.

## Reporting Issues

When reporting an issue, include:

- Intelli Git version
- VS Code version
- Operating system
- Git version
- The repository state involved in the problem
- Steps to reproduce the issue

Do not include private source code, credentials, tokens, or sensitive diff content in public reports.

## AI Provider Issues

For AI commit message generation problems, include:

- Selected provider
- Selected model
- Whether the request uses GitHub Copilot or a custom API endpoint
- The error message shown by VS Code, if any

Do not share API keys.
